# 📖 คู่มือผู้ใช้งาน Expense Bot

คู่มือการใช้งาน LINE Bot สำหรับบันทึกรายรับ-รายจ่ายแบบละเอียด

## 📱 เริ่มต้นใช้งาน

### 1. เพิ่มเพื่อน LINE Bot

1. สแกน QR Code หรือคลิกลิงก์ที่ได้รับจากผู้ดูแลระบบ
2. กด "เพิ่มเพื่อน"
3. Bot จะส่งข้อความต้อนรับ

### 2. ทดสอบการใช้งาน

ลองส่งข้อความ:

```
กินข้าว 120
```

Bot จะตอบกลับด้วย Flex Message ให้ยืนยันการบันทึก! ✅

## 💬 วิธีบันทึกรายการ

### บันทึกรายจ่าย

**รูปแบบทั่วไป:**

```
[รายละเอียด] [จำนวนเงิน]
```

**ตัวอย่าง:**

```
กินข้าว 120
ค่ารถ BTS 44
ซื้อของ 500 บาท
ค่าคอร์สเรียน 1500
ไปดูหนัง 280
```

### บันทึกรายรับ

**ตัวอย่าง:**

```
รับเงินเดือน 30000
ได้โบนัส 5000 บาท
ขายของ 1200
```

### บันทึกด้วยรูปภาพสลิป

1. ถ่ายรูปสลิปหรือเลือกจากแกลเลอรี
2. ส่งรูปให้ Bot
3. Bot จะอ่านข้อมูลอัตโนมัติและส่งข้อมูลให้ยืนยัน
4. ตรวจสอบความถูกต้อง แล้วกด **✓ ยืนยัน**

**หมายเหตุ:** OCR จะแสดงความแม่นยำ (สูง/ปานกลาง/ต่ำ) ให้ตรวจสอบข้อมูลทุกครั้ง

## ✅ ระบบยืนยันการบันทึก

เมื่อส่งข้อความหรือรูปภาพ Bot จะแสดง **Flex Message** ให้ยืนยันก่อนบันทึกจริง

### รายละเอียดใน Flex Message

```
┌─────────────────────────┐
│ ยืนยันการบันทึก      🗑️│ ← Header
├─────────────────────────┤
│ TYPE          CATEGORY  │
│ [💸 รายจ่าย]  [🏷️ อาหาร] │ ← Badges
│                         │
│    TOTAL AMOUNT         │
│      500 บาท           │ ← ยอดเงินขนาดใหญ่
│                         │
│ ┌─────────────────────┐ │
│ │ DESCRIPTION         │ │
│ │ กินข้าว             │ │ ← กล่องรายละเอียด
│ └─────────────────────┘ │
│                         │
│ ┌─────────────────────┐ │
│ │   ✓ ยืนยัน          │ │ ← ปุ่มยืนยัน (เขียว)
│ └─────────────────────┘ │
│ ┌─────────────────────┐ │
│ │   ✕ ยกเลิก          │ │ ← ปุ่มยกเลิก
│ └─────────────────────┘ │
└─────────────────────────┘
```

### การยืนยัน

- **✓ ยืนยัน** - บันทึกรายการเข้าระบบ
- **✕ ยกเลิก** - ยกเลิกการบันทึก

**⏱️ เวลาหมดอายุ:** 5 นาที  
**ป้องกันการกดซ้ำ:** กดยืนยัน/ยกเลิกครั้งเดียวเท่านั้น

### สีของ UI

| ประเภท     | สี Header | สี Amount |
| ---------- | --------- | --------- |
| 💸 รายจ่าย | แดงเข้ม   | แดงสด     |
| 💰 รายรับ  | เขียวเข้ม | เขียว     |

## 🏷️ หมวดหมู่ที่รองรับ

### รายจ่าย

- 🍽️ **อาหาร** - กินข้าว, ซื้อของกิน, ร้านอาหาร
- 🚗 **เดินทาง** - ค่ารถ, น้ำมัน, BTS, MRT, Grab
- 🛍️ **ช้อปปิ้ง** - ซื้อเสื้อผ้า, ของใช้
- 🎬 **บันเทิง** - ดูหนัง, คอนเสิร์ต, เกม
- 🏥 **สุขภาพ** - หมอ, ยา, ฟิตเนส
- 🏠 **ที่พัก** - ค่าเช่า, โรงแรม
- 💡 **สาธารณูปโภค** - ไฟ, น้ำ, เน็ต
- 📚 **การศึกษา** - คอร์สเรียน, หหนังสือ, เทอม
- 🔧 **อื่นๆ** - ไม่อยู่ในหมวดข้างต้น

### รายรับ

- 💼 **เงินเดือน** - เงินเดือนประจำ
- 🎁 **โบนัส** - โบนัส, รางวัล
- 💵 **รายได้อื่น** - ขายของ, รายได้พิเศษ
- 🔧 **อื่นๆ** - รายรับอื่นๆ

## 🔍 การแก้ไขข้อมูล

### ถ้าบันทึกผิด

**วิธีที่ 1: ยกเลิกก่อนยืนยัน**

- กด **✕ ยกเลิก** ใน Flex Message
- ส่งข้อความใหม่ที่ถูกต้อง

**วิธีที่ 2: ถ้ายืนยันไปแล้ว**

- ปัจจุบันยังไม่มีฟีเจอร์แก้ไข/ลบ
- แนะนำ: บันทึกรายการตรงข้าม (ถ้าบันทึกรายจ่าย 100 ผิด → บันทึกรายรับ 100 เพื่อชดเชย)

### ถ้า OCR อ่านผิด

1. ตรวจสอบข้อมูลใน Flex Message
2. ถ้าผิด → กด **✕ ยกเลิก**
3. พิมพ์ข้อมูลเองแทน

## 💡 เคล็ดลับการใช้งาน

### เพิ่มความแม่นยำของ AI

1. **ระบุจำนวนเงินชัดเจน**
   - ✅ `กินข้าว 120`
   - ❌ `กินข้าว` (ไม่มีจำนวน)

2. **ใช้คำกริยาที่ชัดเจน**
   - ✅ `ซื้อเสื้อผ้า 500` (ชัดว่าเป็นรายจ่าย)
   - ✅ `รับเงินเดือน 30000` (ชัดว่าเป็นรายรับ)

3. **เพิ่มคำว่า "บาท" (ถ้าต้องการ)**
   - ✅ `ค่ารถ 44 บาท`
   - ✅ `ค่ารถ 44`

### ถ่ายรูปสลิปให้ชัดเจน

1. **แสงสว่างเพียงพอ** - ไม่มืด ไม่สว่างเกินไป
2. **ตัวอักษรชัดเจน** - ไม่เบลอ
3. **เต็มเฟรม** - ครอบคลุมข้อมูลสำคัญ
4. **ไม่เอียง** - ถ่ายให้ตรง

### ประหยัด AI Quota

- Google Gemini Free Tier: **20 requests/day**
- ถ้าเกิน quota → ระบบจะใช้ Fallback Parser อัตโนมัติ
- Fallback Parser: ดึงจำนวนเงินได้ แต่หมวดหมู่จะเป็น "อื่นๆ"

**แนะนำ:** ใช้ภาพสลิปเฉพาะเมื่อจำเป็น พิมพ์เองเพื่อประหยัด quota

## ❓ FAQ

### Q: ทำไม Bot ไม่ตอบ?

**A:** เช็คตามลำดับ:

1. Bot ออนไลน์หรือไม่? (ดูจากสถานะ)
2. ส่งข้อความถูกต้องหรือไม่? (ต้องมีรายละเอียด + จำนวนเงิน)
3. ติดต่อผู้ดูแลระบบ

### Q: ข้อมูลปลอดภัยไหม?

**A:**

- ✅ มี LINE Signature Verification
- ✅ ข้อมูลเก็บใน PostgreSQL (encrypted)
- ✅ ไม่เก็บข้อมูลส่วนตัว นอกจาก LINE User ID
- ✅ ใช้แค่คุณคนเดียว (ไม่แชร์ข้อมูลข้ามผู้ใช้)

### Q: ลบข้อมูลทั้งหมดได้ไหม?

**A:** ติดต่อผู้ดูแลระบบเพื่อลบข้อมูลทั้งหมด

### Q: แก้ไข/ลบรายการได้ไหม?

**A:** ยังไม่มีฟีเจอร์นี้ในเวอร์ชันปัจจุบัน (วางแผนพัฒนาในอนาคต)

### Q: เปลี่ยนหมวดหมู่ได้ไหม?

**A:** หมวดหมู่ถูกตั้งโดย AI อัตโนมัติ ยังแก้ไขไม่ได้  
**วิธีแก้:** ยกเลิกแล้วส่งใหม่ พร้อมคำที่ชัดเจนกว่า

### Q: รองรับภาษาอังกฤษไหม?

**A:** รองรับแต่ AI ถูกออกแบบสำหรับภาษาไทย อาจไม่แม่นยำ

### Q: ใช้ฟรีหรือเปล่า?

**A:** ขึ้นอยู่กับผู้ดูแลระบบ (LINE API + Google Gemini API อาจมีค่าใช้จ่าย)
